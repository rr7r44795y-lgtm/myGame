# 芳心纵火犯 · 联机骨架（第一版）

## 怎么跑起来

1. 用 Unity 6000.3.23f1 打开 `D:\myGame\MyGame`，第一次打开会自动安装 Netcode 等包。
2. 打开 `Assets/Scenes/SampleScene`，点 Play。所有界面和网络都由代码自动创建，场景里不用摆任何东西。
3. 如果控制台提示找不到网络预制体，点菜单 **MyGame / 生成网络预制体**。

### 一台电脑测联机

- **方法一：Multiplayer Play Mode（推荐）**：菜单 Window → Multiplayer → Multiplayer Play Mode，勾选 Player 2（最多 4 个）。点 Play 后会多开几个窗口，一个建房，其他的进「加入房间」就能在列表里看到。
- **方法二：打包多开**：菜单 **MyGame / 打包 Windows 测试包**，输出到 `Builds/Win/MyGame.exe`，双击多开。
- 同一台电脑只能有一个房主（端口 7777 被占用）。

### 自动测试

- **单人流程**：Window → General → Test Runner → PlayMode → `SmokeTest.HostFlow`。
- **双人联机**：用打好的包分别以 `-autotest host` 和 `-autotest client` 启动两个进程，日志里 `[AUTOTEST] PASS` 表示通过。

## 操作

| 按键 | 作用 |
|-|-|
| WASD / Shift / 空格 | 移动 / 奔跑 / 跳跃（房间里空格是唤起聊天） |
| 鼠标 | 视角 |
| E | 拾取物资、在水井喝水 |
| 1 2 3 | 切换快捷栏 |
| 鼠标左键 | 使用选中物品：食物和饮料长按 3 秒，道具点按 |
| G | 对着其他玩家，把选中物品送出 1 个 |
| B | 背包 |
| C | 个人信息 |
| Esc | 关闭面板 / 释放鼠标（点画面空白处恢复） |

## 同步规则

- **位置和朝向**：本人计算，其他人通过 NetworkTransform（Owner 模式）看到。
- **其他一切都由房主（服务器）说了算**：玩家列表、阶段与倒计时、阵营分配、物资生成与拾取、背包、饱腹水分、死亡、送礼、好感度。客户端只发请求，结果同步回来。
- **好感度和喜好**：只存在房主机器上；喜好会单独发给本人一份，用于个人信息面板，其他人拿不到。
- **局内地图**：每台机器按固定种子在本地生成，不走网络。

| `Scripts/Game` | `Session`（房间与对局流程）、好感度、灰盒地图 |

| `Editor` | 生成网络预制体、打包 |
| `Resources/MyGame` | 网络预制体、UI 样式 |
