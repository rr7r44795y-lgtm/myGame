## 打开方式

使用项目锁定的 Unity **6000.3.23f1** 打开仓库，打开 `Assets/Scenes/FoundationDemo.unity`，点击 Play，先创建房间，点击 `Add demo member` 加入一个模拟成员（凑到 2 人），再点击 `Start game`。演示场景已放在 Build Settings 的第一位；原来的 SampleScene 保留。

这是本地可交互的基础演示，不是已经完成联网同步的多人游戏。房主权威流程、多人名册、全部确认提前开始以及人数平衡都存在于纯 C# `MatchSession` 中；需要后续房间系统调用并传输状态。

## 六张表的数据配置

编辑 `Assets/Foundation/Resources/SupplyTables.json`。总表 `id` 与四种子表的 `key` 一一对应；子表自身的 `id` 在该子表内唯一。枚举数字：Food=0、Water=1、HighValue=2、Ordinary=3。`address` 使用 `{x,y,z}`，`type` 是点位允许的物资类型数组，`number` 是单次该点位掉落数量。

`maxStack`、`canGift`、`iconResource`、点位 `chance` 是额外可配置字段。示例中的可赠送标记不代表赠送玩法已完成。饥饿和口渴仅在使用物资时变化；特殊玩法、自然衰减等没有文档参数支持。

## 验收

1. 完全不选，等待 10 秒：自动得到 1 个喜欢和至少 1 个不同的厌恶，进入 20:00 局内。
2. 重启 Play，手动选择喜欢、厌恶并确认：立即进入局内。选中喜欢项不能同时选为厌恶；第四个厌恶无法选入。
3. 物资在指定点位生成。鼠标朝向近处物资按 E：背包数量增加，世界物资消失。
4. 按 B 打开背包：角色停止移动 / 转向；选择背包槽与快捷槽交换；关闭后恢复控制。
5. 数字 1–5 切换物品；左键使用食物 / 水，消耗 1 件；普通 / 高价值物资未配置特殊用途时不消耗。
6. 等待刷新：未拾取的点位不增加第二堆；空点位按概率补货。
7. C 打开个人信息，Esc 打开设置，Tab 释放鼠标后可点 HUD 按钮；各面板互斥；所有局内面板打开时比赛时钟继续运行。
8. 时间到达 00:00：显示结束面板，不能继续拾取、使用或移动，不生成额外物资。

纯 C# 回归：`bash tools/test-foundation.sh`（需 Mono）。Unity EditMode 回归：Window → General → Test Runner → EditMode → Run All。

当前运行环境没有 Unity Editor。核心模型测试不等于 Unity 画面、输入、URP 或构建已经通过；这些需在 6000.3.23f1 完成上述实际验收。
